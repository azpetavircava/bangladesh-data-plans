## 网络设置：让信号“满血”的秘诀

　　卡插进去没网络？十有八九是APN没设置对。

　　拿到新卡，装进手机后第一件事，就是手动设置APN。这个信息通常会在SIM卡的大卡托上，或者问柜台工作人员要。以Grameenphone为例，APN一般是“gpinternet”，其他字段留空即可。

　　设置完记得重启手机！这个简单动作能解决八成以上的连接问题。

　　另外，检查一下你的手机网络频段是否支持。孟加拉国主要用900MHz和1800MHz，绝大多数现代手机都没问题。但如果你用的是某些特定型号的国产手机，最好提前查一下频段支持列表。
